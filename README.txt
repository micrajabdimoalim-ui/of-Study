MICRAJ AI UNIVERSITY STUDENT QUERY PORTAL

Open index.html directly in a browser.

STUDENT ACCOUNT:
Students enter Registration No., Name, Department, Email, Program and Year of Study when submitting a query. Their registration number is used to view their queries in this demonstration.

ADMIN ACCOUNT:
Username: admin
Password: admin123

ADMIN FEATURES:
- Manage COD, Secretary, Dean and DVC routing.
- Send messages to students.
- Mark queries Solved, Not Solved, In Progress or Waiting.
- Manually escalate to the next office.
- Automatic 48-hour delay detection.
- Automatic student notification and escalation after 2 days.
- Statistics for query categories, solved, not solved, delayed and escalated.
- Performance table showing how many queries COD, Secretary, Dean and DVC received, solved, did not solve, were delayed and escalated.

This is a browser-only demonstration using localStorage. A production deployment should use a server database, real authentication, email/SMS notifications and a server-side scheduler.
